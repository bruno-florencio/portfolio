# Bruno Florencio — Portfólio

Portfólio de projetos em **NoCode**, **automações** e **Prompt Engineering / IA**. Site bilíngue (PT/EN) feito com Next.js + Tailwind e publicado na Vercel.

## Editar o conteúdo

Todo o texto (sobre, ferramentas, projetos, serviços e contatos) fica em [`data/content.ts`](data/content.ts). Para adicionar um projeto, copie um item da lista `projects` e preencha `title`, `description` (pt/en), `tags`, `link` e/ou `repo`.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
